## Overview

Docteur360 is a full-featured healthcare platform designed to bridge the gap between doctors and patients in Algeria. The platform streamlines the appointment process while supporting multiple consultation types—**home visits**, **office appointments**, and **video consultations**—making healthcare more accessible than ever.

## Key Features

### Multi-Portal Architecture
- **Doctor Portal**: Complete practice management with subscription-based access to appointment features, patient management, and consultation scheduling
- **Patient Portal**: Easy appointment booking, doctor discovery, medical history access, and video consultation capabilities
- **Admin Panel**: Comprehensive dashboard for platform management, user oversight, and analytics

### Flexible Consultation Types
- **Office Visits**: Traditional in-clinic appointments with real-time availability
- **Home Consultations**: Doctors can offer home visit services for patients who need them
- **Video Consultations**: Integrated with a self-hosted video conferencing service for secure, HIPAA-aware telemedicine appointments

### Payment & Subscriptions
- **Subscription Model**: Doctors subscribe to unlock appointment and consultation management features
- **E-Payment Integration**: Native Algerian payment gateway integration for seamless DZD transactions
- **Third-Party Payment Providers**: Extended payment options through integrated external providers

### Advanced Search & Discovery
- **Smart Search Engine**: Filter doctors by specialty, location, services, availability, and ratings
- **Geolocation Integration**: OpenStreetMap-powered location services for finding nearby healthcare providers
- **Category & Service Filters**: Browse by medical categories, consultation types, and specific services

### Medical Content Platform
- **Built-in Medical Blog**: Thousands of curated medical articles across multiple health categories
- **Health Education**: Informative content to help patients understand conditions and treatments
- **Category-Based Navigation**: Easy browsing through medical topics and specialties

### Communication & Notifications
- **SMS Notifications**: Real-time appointment reminders and status updates via SMS gateway
- **Email Campaigns**: Automated email notifications for bookings, confirmations, and follow-ups
- **In-App Chat System**: Legacy built-in messaging for doctor-patient communication

### Authentication & Security
- **Social Login**: Quick authentication via LinkedIn and Google OAuth
- **Secure Sessions**: Robust session management with Laravel's built-in security features
- **Role-Based Access**: Granular permissions for doctors, patients, and administrators

## Technical Implementation

Built with a modern, maintainable stack following clean code principles:

- **Backend**: Latest Laravel framework with PHP, emphasizing clean architecture and maintainability
- **Frontend**: Blade templating engine with jQuery for dynamic interactions
- **Database**: MySQL with optimized queries and proper indexing
- **Video Service**: Self-hosted WebRTC-based solution for video consultations
- **Maps**: OpenStreetMap integration for geolocation and doctor discovery
- **APIs**: RESTful API architecture for mobile app integration and third-party services

## Impact

Docteur360 has transformed healthcare accessibility in Algeria by providing a unified platform where patients can easily find, book, and consult with healthcare professionals—whether in person or remotely—while giving doctors the tools they need to manage their practice efficiently.
